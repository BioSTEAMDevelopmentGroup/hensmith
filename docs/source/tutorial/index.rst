Tutorial
========

A staged, hands-on tour of hensmith: the quickstart system end to end, the
pinch analysis behind its utility targets, the anatomy of the synthesized
network, how to configure the facility and apply it to a larger system, and
targeting utilities, area, units and cost to choose the minimum approach
temperature of the least total annualized cost.
Every code block on these pages is included from a script under
``docs/_demo_src/examples`` that also produced the figures and outputs shown,
so what you read is what ran.
